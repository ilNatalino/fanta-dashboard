# Issue tracker: Local Markdown

Issue e specifiche vivono come file Markdown sotto `.scratch/`.

## Conventions

- Una directory per funzionalità: `.scratch/<feature-slug>/`
- La specifica è `.scratch/<feature-slug>/spec.md`
- I ticket sono `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Lo stato di triage è indicato da una riga `Status:`
- Commenti e cronologia sono aggiunti sotto `## Comments`

## Publishing

Pubblicare una specifica significa creare il relativo file sotto `.scratch/<feature-slug>/`.
