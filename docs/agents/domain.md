# Domain Docs

Prima di esplorare o modificare il progetto, leggere:

- `CONTEXT.md`;
- gli ADR pertinenti eventualmente presenti sotto `docs/adr/`.

Il repository usa un layout single-context. Nei documenti, nei test e nelle issue devono essere utilizzati i termini definiti nel glossario, evitando i sinonimi esplicitamente esclusi.

Gli eventuali conflitti con un ADR esistente devono essere segnalati invece di sovrascrivere implicitamente la decisione.
